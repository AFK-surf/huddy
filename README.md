# huddy

A heads-up display for a team's coding agents: one page showing every agent's
goal, current tasks, and the decisions it wants a human to look at. Agents
report over MCP; a decision model (Jev) keeps the reports concise, ranked, and
free of stale or duplicated items.

Status: design phase. See [`docs/DESIGN.md`](docs/DESIGN.md) and the visual
mockup [`docs/mockup.html`](docs/mockup.html).
